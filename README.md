# PEファンド道場 — Private Equity Investment Dojo

**白紙の状態から、投資委員会で自分の言葉で発言できる投資プロフェッショナルへ。**

PEファンドの投資プロセスを遂行するために必要な知識を、
**18トピック × 3レベル（初級／中級／上級）** の座学と理解度クイズで徹底的に訓練する、
ブラウザだけで動く学習アプリです。

---

## 使い方

インストールもビルドも不要です。

```bash
# リポジトリを取得して index.html を開くだけ
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

`file://` で直接開けます。ローカルサーバで動かす場合は：

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

進捗はブラウザの `localStorage` に保存されます（進捗ページからエクスポート／インポート可）。

### 機能

- **座学**：各トピック×レベルの解説（目次付き、レベル間を自由に往復可能）
- **理解度クイズ**：選択肢はシャッフルされ、全問に詳細な解説付き
- **復習箱（SRS）**：Leitner方式の間隔反復（1→3→7→21→60日）。誤答は箱が2つ戻る
- **実戦ドリル**：レベル・トピック・出題範囲（未着手／誤答歴／付箋）を自由に組み合わせ
- **模擬IC試験**：4つのプリセット（新人卒業試験／アソシエイト実務試験／IC試験／道場総覧）
- **用語集**：主要用語を検索可能
- **進捗管理**：トピック別習熟マップ、学習履歴、エクスポート／インポート
- **キーボード操作**：`1`〜`6` で解答、`Enter` で次へ
- **ダークモード**対応

## 推奨する学習ルート

1. **初級を全トピック通す。** 第1講から順に、各トピックで「座学 → クイズ → 誤答の解説」。
   正答率85%を超えるまで同じレベルを回す。
2. **中級は「手を動かす」順。** LBOモデル・財務DD・タームシート・SPAを重点的に。
   Excelを開いて再現しながら解くと定着が段違い。
3. **上級は横断で解く。** ストラクチャー・税務・会計・契約は相互に絡む。
   模擬IC試験でトピック混在の出題を受け、「どの論点か」を自分で判別する訓練を。
4. **毎日、復習箱をゼロにする。** 間隔反復で長期記憶に落とす。

## コンテンツの追加・修正

### 問題を追加する

`data/quiz/<topic>-<level>.js` に追記します（`level` は `b`／`i`／`a`）。

```js
DOJO.quiz('acct', 'i', [
{
  q: '設問文',
  stem: '（任意）前提条件や数値の提示',
  choices: [
    '正解の選択肢',   // ← 必ず先頭に正解を書く
    '誤答1', '誤答2', '誤答3'
  ],
  a: 0,               // 正解のインデックス（0固定でよい）
  exp: '解説（Markdown可）',
  tags: ['タグ']
}
]);
```

**選択肢は表示時に必ずシャッフルされる**ため、正解は先頭に書いて `a: 0` としておけば十分です。
「上記のすべて」「AとBの両方」のような順序依存の選択肢は使わないでください。

### 座学を追加・修正する

`data/lectures/<topic>.js` の `b` / `i` / `a` に Markdown 文字列で記述します。
見出し（`##`／`###`）は自動的に目次になります。

独自記法：

- `::: タイトル` 〜 `:::` … 囲み記事（Callout）
- `{{強調}}` … アクセント色
- `==ハイライト==` … マーカー

### トピックを追加する

`data/curriculum.js` の `DOJO.TOPICS` に定義を追加し、
`data/lectures/<id>.js` と `data/quiz/<id>-{b,i,a}.js` を作成すれば、
ローダーが自動的に読み込みます（データが無いトピックは「準備中」と表示されます）。
