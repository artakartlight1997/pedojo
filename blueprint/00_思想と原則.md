# 00. 思想と原則 — PEファンド道場 v2「投資プロへの道」

> この文書は、道場をゼロから作り直すための最上位の思想。以降のすべての設計文書（01〜09）はこれに従う。
> 迷ったらここに戻る。

## 0. 一文で言うと

**「素人を、PEファンドの投資プロフェッショナルに育てる。知識を増やすのではなく、仕事ができるようにする。」**

評価軸は一つだけ。
**「この人に案件を任せられるか」**。
用語を知っているか、計算ができるか、はその手段にすぎない。

---

## 1. なぜ作り直すのか（v1の失敗の本質）

v1は「27トピック×4レベル＝108講＋4,309問」を作った。量は出た。しかし根本の設計を誤っていた。

| v1の設計 | 何が起きたか |
|---|---|
| **知識領域**（会計・税務・法務…）でカリキュラムを切った | 「仕事の流れ」でなく「教科書の目次」になった。学ぶ側は、自分が今どの仕事をできるようになったのか分からない |
| 初級＝**用語と定義** | 「ティーザーとは何か」「Jカーブとは」を4択で当てる訓練になった。言葉を知っても、月曜朝に何をすればいいか分からない |
| **4択がほぼ全部**（96%） | 「正解を選ぶ」訓練になり、「自分で論点を立て、数字を作り、判断を言葉にする」訓練にならなかった |
| 講義は**百科事典**型（1講10節） | 網羅はしているが「このスキルをどう使うか」「どう身につくか」の順序がない |
| **モデル＝LBOモデルの作り方** | モデルは手段の一つなのに、モデルが組めれば一人前かのように扱った。「モデルを分解し、前提を疑い、モデルの外にある判断」が抜けた |
| ケーススタディがない | 「一つの案件を最初から最後まで自分で運ぶ」経験がゼロ。分断された知識は現場で結合しない |
| 「5,000問」を目的化 | 本来は手段。問題数を増やすこと自体が作業の目的になった |

**要するに、「知っている」を増やす設計であって、「できる」を作る設計ではなかった。**

## 2. プロとは何か（到達点の定義）

PEファンドの投資プロとは、次の5つを一人で（あるいはチームを率いて）回せる人。

1. **案件を見つけ、見立てを立てる**（ソーシング・スクリーニング・投資仮説）
2. **値付けし、資金を組む**（バリュエーション・LBO・デット）
3. **調べ抜いて、価格と契約に落とす**（DD・交渉・SPA）
4. **買った会社の価値を上げる**（100日プラン・ガバナンス・経営陣）
5. **売って、資金の出し手に返す**（exit・LP）

このサイクルを、**自分の職位に応じた責任範囲で**遂行できることがプロの定義。
アソシエイトなら「落とさず・間違えず・速く」成果物を作れること。VPなら案件を閉じられること。ディレクターなら案件を作れること。

**習得の順序は「全体を薄く一周→厚く一周→もう一周」。** 最初から各領域を深掘りしない。素人は「流れ」が見えないと何も身につかない。

## 3. 10の設計原則

### 原則1：単位は「スキル」ではなく「仕事」
カリキュラムの基本単位は、**実際の業務プロセスの一工程**（例：「IMを読んで初回スクリーニングメモを書く」「紙LBOで入札上限の目安を出す」）。その工程をやるために必要な知識・スキル・判断を、その場で教える。知識領域（会計・税務…）は索引であって、カリキュラムの骨格ではない。

### 原則2：講義→手本→真似→独力→振り返り（守破離）
一つの工程を学ぶ手順は固定する。
1. **講義**：なぜこの工程があるのか、何を作るのか、どう評価されるのか
2. **手本（ワークド・エグザンプル）**：プロが実際にやる様子を、思考過程ごと見せる
3. **真似（ガイド付き演習）**：穴埋め・部分修正・順序並べ替えで、手本の型をなぞる
4. **独力（ドリル・ミニケース）**：自分で論点を立て、数字を出し、判断を言葉にする
5. **振り返り（判断ジャーナル）**：何を見落としたか、プロならどう考えるか

### 原則3：モデルは「使える→分解できる→疑える→超えられる」
モデリングは四段階で教える。
- **使える**：型どおり組める（ソース&ユース、3表、デットスケジュール、リターン）
- **分解できる**：リターンを「倍率拡大・EBITDA成長・レバレッジ・デット返済」に分解し、どの前提が結論を動かしているか言える
- **疑える**：前提のどこが怪しいかを事業・現場・人の情報から指摘できる
- **超えられる**：モデルが答えられないこと（経営者の質、業界構造の変化、関係性）を判断に織り込める

**「モデルだけではだめ」を最初から教える。** モデルは思考を整理する道具であり、投資判断の代替ではない。

### 原則4：一本のケース（通しディール）が背骨
素人をプロにするには、**一つの案件を最初から最後まで自分の手で運ぶ経験**が要る。架空だが徹底的にリアルな案件（「株式会社◯◯精機」のような日本の中堅企業）を一本通し、ソーシングからexitまで、各段階で学習者が成果物を作る。これが道場の背骨。

その背骨に、**複数の短いケース**（カーブアウト、事業承継、非公開化、ターンアラウンド、破談案件…）を枝として付け、型の転用を鍛える。

### 原則5：問題は「正解を選ぶ」でなく「判断を作る」
4択は使うが、主役ではない。主役は：
- **「次に何を確認するか」**を選ぶ・並べる問題
- **「この数字のどこがおかしいか」**を見つける問題
- **「ICで聞かれる質問を3つ書け」**という生成問題（自己採点ルーブリック付き）
- **「この状況で、あなたの上司に何と報告するか」**という作文問題
- **紙計算**（暗算で入札上限・IRR・レバレッジ目安を出す）

4択を使うなら、選択肢は「全部一理ある判断」で構成し、**なぜその判断が最善かを根拠から選ばせる**。

### 原則6：初級は「用語」ではなく「仕事の全体像と、最初の1年でやる工程」
初級のゴールは「会議の議論が聞き取れる」ではなく、**「アソシエイト1年目の仕事（スクリーニング、モデル初稿、Q&A管理、議事録、資料作成）を、意味を理解して遂行できる」**。用語はその過程で必要になった瞬間に、その場で教える（原則2）。

### 原則7：日本のPE実務に根ざす
事業承継・カーブアウト・非公開化（MBO/TOB）・地銀との関係・仲介会社・表明保証保険・経営者との信頼・終身雇用と労組・取締役会の実態——日本固有の現実を主軸に置く。KKR/Carlyle/Blackstoneの型は「世界標準」として参照し、日本の現場でどう翻訳されるかを示す。

### 原則8：判断の根拠を言葉にする訓練を最重視
プロの差は「知っている量」ではなく「判断を言語化できるか」にある。ICメモ、投資仮説、リスクと緩和策、「何を信じる必要があるか（What we need to believe）」、プレモーテム——すべて**書かせる**。自己採点できるルーブリックを必ず付ける。

### 原則9：測定できるものだけを進捗と呼ぶ
「問題を何問解いたか」は進捗ではない。進捗とは：
- 通しケースのどの工程まで、どの品質で成果物を作れたか
- 判断問題の正答率・紙計算の速度と精度
- 判断ジャーナルの蓄積と、過去の自分との差

### 原則10：量は手段。5,000本ノックは「判断の反復」のために使う
5,000問は維持してよい。ただし、**その配分と型を変える**。用語確認は最小限（全体の10%以下）、大半を「工程ごとの判断ドリル」「数字の検算」「場面判断」「ミニケース」に振る。問題は講義・ケースに紐づき、「今やっている工程」の反復として出る。

## 4. 対象者と到達レベル

| 対象 | 開始時 | 到達点（道場完走時） |
|---|---|---|
| 本人（素人） | 会計・金融の基礎知識なし。PEの仕事内容を知らない | PEファンドのアソシエイト〜シニアアソシエイトとして**実務を主担当で回せる**水準。VP以上の判断の型を理解し、自分の判断を言語化できる |

「天才級」を目指すが、道筋は「まず一人前、次に一流」。一人前の基準＝**通しケースを独力で完走でき、各工程の成果物がプロの採点ルーブリックで合格水準**。

## 6. 成功の定義（この作り直しが成功したと言える条件）

1. 素人が **第1章から順に進めば、途中で「何のためにこれを学ぶのか」が分からなくなる瞬間がない**
2. 各章の終わりに、**自分で作った成果物**（スクリーニングメモ、紙LBO、DD論点リスト、ICメモ…）が手元に残る
3. 通しケースを完走すると、**一つの案件を最初から最後まで運んだ疑似経験**ができている
4. 問題の大半が「判断」を問い、用語問題は脇役になっている
5. 「モデルは組める、分解できる、疑える、モデルの外も判断できる」の四段階が、学習者本人に自覚できる
6. 日本の現場（事業承継・地銀・仲介・経営者）が主役であり、海外の型はそれを照らす参照として配置されている
