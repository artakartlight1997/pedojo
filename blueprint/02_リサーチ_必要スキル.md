### 1-2. 職位ごとの観察可能な行動（実務者フォーラム・面接ガイドから）
**アナリスト／アソシエイト（0〜4年）**
- ゼロからLBO（ソース&ユース・3表・複数トランシェ・リターン）を2〜3時間でミスなく組む。「モデルの全ドライバーと、どのレバーがリターンをどう動かすか」を聞かれる前に試している
- 100頁のIMを2〜3頁の社内スクリーニング要約にする（IM精読＋IC初稿で13〜18時間が目安）
- ICメモ初稿：投資仮説を「**委員が反論できるほど具体的な2〜3の主張**」として書く。基本／下方／上方ケース、リスクと緩和策の対、未解決事項
- DDワークストリームを一本持つ：会計士・弁護士・コンサルの調整、トラッカー管理、発見事項をモデルとメモへ反映
- **「チェックされなくても正確」**。PEでは「対外に出る前に作業はチェックされず、ICの前にモデルは緩くしか見られない」——ミスのない成果物が最初の評判を作る
- 「角の先を見る」：次の質問を予測し、聞かれる前に感応度を送る
- 事業を平易な言葉で説明できる：何を誰に売り、なぜ顧客は残り、何が壊すか

**シニアアソシエイト／VP（4〜8年）**
- 「技術的実行」から「組織的な案件管理」への転換。DDスコープを決め、アドバイザーを選び予算を交渉し、プロセスレターの日程に対して進行を管理
- テンプレを埋めるのではなく仮説を書く。「真でなければならない3つのこと」を決め、それを攻めるDDを設計（Bainの「ディール仮説主導DD」）
- LOI/タームシート/SPAのビジネス論点を弁護士と一次交渉。銀行側も管理
- 経営陣面談を主導し、CEO/CFOへの見立てを持ち、防衛する
- ICの事前根回し：Blackstoneではメモは2日前配布、会議は弱点に集中し全員が発言する——VPは攻撃を予期していなければならない
- クロージング後：オペレーションチームと100日プラン、取締役会準備、四半期の再アンダーライティング

**プリンシパル／MD（8年〜）**
- 「独自案件を一貫して持ち込むレインメーカー能力」と「投資先の取締役会を運営する厳密な経営管理能力」の稀な組合せ。SPAの主交渉者。クロージング後はCEOとの関係を所有する取締役
- セクター仮説と独自の関係マップを持ち、関係を角度（先制入札・提携・カーブアウト）に変換
- 降りる判断：Kravis「常に下方で何を失い得るかを心配せよ」、Schwarzman「第一則：金を失うな」
- CEOを採用・交代させ、経営陣インセンティブを設計する——Kravis「会社を買うだけでなく、正しい経営陣を選び正しいインセンティブを与えること」
- 文化を背負う：「we, not me」（案件を持ち込んだかに関わらず経済を共有）、「10点の人材だけ採る」（問題を察知し、解決策を設計し、指示されずに事業を新しい方向へ動かす）

### 1-3. 投資プロセスと、ジュニアが各工程で作るもの
KKRのICは月・木開催。スクリーニング1〜2週、DD2〜6週、ストラクチャー・契約・承認1〜2週。同じ案件チームが着手からexitまで担当し、ICは初期スクリーニングからアンダーライティングまで関与。別途ポートフォリオ管理委員会。

| 工程 | 何が起きるか | ジュニアの成果物 |
|---|---|---|
| ソーシング・テーマ | セクター仮説、銀行カバレッジ、CEO関係。EQTはMotherbrain（AI/データ）でソーシング・ボルトオン・産業アドバイザー発見。Carlyleは「One Carlyle」で全プラットフォームを動員 | セクター俯瞰資料、ターゲットリスト、「魅力的テーマ」メモ（KKR求人票に明記）、銀行面談メモ、月曜パイプライン会議の更新 |
| スクリーニング | 中規模ファンドは年80〜100本のIMを見て約10%が進む | 2〜3頁のIM要約、紙LBOの概算リターン、「進める／見送る」と理由3つ |
| 一次入札 | 非拘束レンジ、短いIC議論 | 初稿LBO、暫定ICメモ（5〜10頁）、バリュエーション・ブリッジ、一次入札レター草案 |
| マネプレ・DDスコープ | 商業・財務/QoE・法務・税務・IT・ESG・保険。オペレーションチームが参加（KKR Capstoneは「資産選定の段階で案件チームと協働」、Blackstoneはオペレーティングパートナーを案件チームに埋め込み、TPG Opsは「案件チームに完全統合され同じキャリーを分ける」、Carlyle GPSはDDに機能的洞察、CVCのオペレーティングパートナーはDDに参加しVCPを形作る） | DD依頼リスト、経営陣への質問リスト、アドバイザーのスコープレター、データルーム索引、面談ノート |

| クロージング→100日 | 案件チーム＋オペレーションチームの共同100日プラン：安定化・統制、クイックウィン、ガバナンス・KPIの定期化 | KPIダッシュボード、取締役会資料テンプレ、施策トラッカー、予算レビュー |
| 保有 | 成長・価格（Thoma Bravo）・調達（Blackstoneはポートフォリオ300億ドル超の購買力）・デジタル・人材・ボルトオン | 四半期再アンダーライティング、取締役会資料、ボルトオン審査モデル、ポートフォリオレビュー |
| exit | デュアルトラック、VDD、エクイティストーリー、データルーム、買い手の事前打診（上市2〜3か月前） | VDD調整、エクイティストーリー資料、exitモデルとリターン分解（EBITDA成長 vs 倍率 vs 返済） |

### 1-4. 育成の実態と「ケースメソッド＝本当のカリキュラム」
- 投資銀行の基礎研修：JPMorganは4〜6週（会計・Excel・PowerPoint・Bloomberg）、Goldmanは約2週。外部プロバイダ（Wall Street Prep：3日のモデリング合宿＋PE合宿は「案件プロセス（ティーザー→一次入札→DD→LOI→クロージング）から始めてLBO」、「トップ5のPEのうち4社が新人研修に使用」★；Training The Street；Pillars of Wall Street）
- PE入社後：Bain Capitalは「数週間の集中研修で付加価値投資アプローチを導入」、CVCは「正式な技術研修」。ある事例では1週目に投資プロセスを初期資料から最終ICまで通し、2週目に「モデルを所有する」、その後IC資料作成。**実務者の共通認識：正式研修は薄く、ライブ案件での徒弟制が本体**。「最初の案件があなたへの評価に過大な影響を与える」
- **採用のケース＝実際のカリキュラム**：①紙LBO（5〜10分、ペンのみ：前提→S&U→FCF→返済→exit→MOIC→IRR、面接官は推論の連鎖を追う）②時間制モデリングテスト（1〜3時間；大手は2〜3時間、構築後30分「前提について詰められ、どこを深掘りするか、事業の真のレバーは何か」）③持ち帰りケース（2〜7日、「モデル60%・仮説と資料40%」）
- **判断の試し方**：「PE面接は技術の衣装をまとった判断力面接」。「案件を説明せよ」（仮説・自分の役割・本当のリスク・評価・結果。3分版と30分版）、「会社をピッチせよ」（2文の仮説・2つの本物のリスク・スポンサーが買収後にやること）、「当社のポートフォリオで見送るべきだったのは？」、「何があれば降りるか」

### 1-5. 一流の投資家を分けるもの（実務家の言葉）
- **Kravis**：誠実さの次に植え付けたい一つの資質は好奇心。「常に下方で何を失い得るかを心配せよ」。若い投資家は「引き金を引くのに苦労する」。「会社を買った時に祝うな。どんな馬鹿でも会社は買える。売って本当の価値を作った時に祝え」
- **Schwarzman**：「金を失うな」。人格を切り離したIC（文書メモ・2日前配布・全員発言・弱点探し）。「10点」を採れ
- **Rubenstein**：一流は「知的スポンジ」、読書家、逆張りで失敗から素早く立ち直り、独立した思考と謙虚さ（「間違うことへの健全な恐れ」）を併せ持ち、「ストレステストしてくれる」他者と働ける
- **Orlando Bravo**：「3〜5年で事業の軌道を本当に変えるのは非常に難しい。だから1つか2つの価値創造レバーに現実的に取り組む」。経営者評価＝開放性・数字への関心・部下の追随。価格規律。収益性と成長は両立させる
- **Apollo**：「購入価格が重要」。規律・複雑性・創造性・下方保護
- **Bain『Lessons from Private Equity』**：フルポテンシャルの定義、ブループリント、重要なものだけ測る（現金と主要オペ指標）、オーナーのように考える飢えた経営者、エクイティに汗をかかせる
- **『Barbarians at the Gate』『King of Capital』**：レバレッジはリターンと倒産リスクの両方を増幅する。自我と弱いガバナンスが価値を壊す。インセンティブがオークションを形作る

**統合**：有能＝モデルの正確さとプロセス遂行。一流＝(1)差別化され反証可能な仮説 (2)執念的な下方の見立て (3)正直な経営者評価 (4)1〜2のレバーを選んで実行 (5)降りることと踏み込むことの両方ができる。

## 2. 日本のPE — 市場構造が要求スキルを決める

### 2-1. 市場の数字（スキルの背景）
- **案件数**：2024年の投資会社によるバイアウト系M&Aは205件（前年152件、+34.9%）で過去最多、**うち事業承継107件（5割超）**、金額1兆9,523億円（レコフ）。ベイン集計では2024年ディール総額3.1兆円、exit 1.9兆円/51件、2025年は4.8兆円★。1億ドル超のバイアウトのうち**カーブアウトは2024年で20%**、2013年以降累計25%超
- **非公開化**：2025年のMBOは30件（前年比7割増、過去最多）★。TOBプレミアム平均約47%★。買い手にファンドが入る案件が約27.5%。背景は東証の資本効率改革（PBR1倍問題）・アクティビスト・上場維持コスト
- **LBOローン**：残高2019年3月2.6兆円→2023年9月6.6兆円、3メガが約80%（金融庁・日銀）。典型的資本構成：シニア50〜60%／メザニン10〜20%／エクイティ30〜40%、レバレッジ目安EBITDAの4〜5倍、コベナンツはDSCR・レバレッジ比率・純資産維持・黒字維持。2026年に国内LBO向けプライベート・デット・ファンド（約500億円）も登場★
- **地銀**：地銀・第二地銀99行のうち**約65行が事業承継ファンドを運営**。ファンド経由の事業承継M&Aは「10年で10倍、2024年に100件超」（日経）。地銀は**紹介者・LBOレンダー・競合ファンド・共同投資家の4つの顔**を持つ
- **表明保証保険**：PE売主案件では48%で利用★。限度額は取引額の10〜25%、免責0.5〜1%。中小M&A向け低額商品も登場
- **ルール**：経産省「公正なM&Aの在り方に関する指針」（2019）、「企業買収における行動指針」（2023）。特別委員会・マジョリティ・オブ・マイノリティ・フェアネスオピニオンが非公開化実務の中核
- **人材**：バイリンガルの**シニアアソシエイト〜ディレクター層が極端に薄い**。各社の育成は完全にOJT依存。経営人材も不足（ベインがBCEPを内製した理由）

### 2-2. 職位別の要求（日本の求人票・エージェント・各社の言葉）
**アソシエイト（25〜29歳中心）**
- 3表連動LBOを60〜90分で構築し、価格・レバレッジ・返済・exit倍率・IRR/MOICの**感応度を口頭で説明できる**（選考＝紙LBO・Excel実技・DCF口頭試問が標準）
- 「何件やったか」ではなく「**どの投資前提を検証し、どの下方リスクを価格・条件にどう反映したか**」を語れる（コトラ）
- DD外部アドバイザーの手配・論点管理、IC資料の一次ドラフト、投資先の月次定例出席
- 「吸収力の速さ」が最大のキー（アンテロープ）。IBD/戦コン出身者が好まれる理由＝コーポレートファイナンスの基本・ビジネスの基本・新しいことを素早く習得
- **対人**：経営者や年配者に「可愛がられ、信頼される」タイプ。**カーライルは「人間味・愛きょうのある人」と明言**。弁護士・会計士・コンサルを束ねる力
- 自律性：「自ら先回りして課題を発見し、解決策の提案とともに報告する」

**シニアアソシエイト／VP（30代前半）**
- 成果物の品質保証者。昇格条件の第一は「ハードスキルが高いこと」
- ソーシング先（仲介・地銀・FA）との関係維持、SPA/株主間契約の論点交渉、LBOローンのタームシート交渉、W&I付保設計、特別委員会対応
- 投資後は取締役として会議体を設計し、KPI（売上・粗利・NWC）とキャッシュブリッジを60分会議で回す

**ディレクター／プリンシパル**
- 案件オーナー。ICで投資仮説・バリューアッププランを通し、「他社より大きくバリューアップできる提案を仕立てて、より高く買う」（カーライル）論理を構築
- 投資先社長・CFOの採用・交代判断、プロ経営者ネットワークの活用。地銀・メガ・仲介との継続的な関係資本

**パートナー**
- ファンドレイズ、ソーシングの最上流（オーナー・大企業本社・社外取との信頼）、exit判断。インテグラルではパートナー自身が投資先社長に就く例も
- 日系独立系は20人弱の「パートナーシップ」組織。「個々人が自分の仕事を責任を持ってやり切る」が規範

**横断的資質**：APの4行動原理（Client / Quality / Initiative / Fairness Advantage）、ユニゾン「経営者・従業員・株主が同じ価値観を共有」、NSSK「人として正しいことを貫く」——**ハードスキルより行動原理**を掲げる会社が多い。

### 2-3. 日本固有の案件型ごとの固有スキル
| 案件型 | 固有に要るもの |
|---|---|
| **事業承継（件数の5割超）** | オーナーの心情理解（「社員や取引先に堂々と説明できる選択」「第二の創業」）。雇用維持・共感・成長の3要件を提案に織り込む。担当者との相性・信頼が売り手の決定要因。現経営陣続投か外部社長かの判断、ワンマン経営のガバナンス移行、管理会計の不在への対処。仲介会社・地銀経由ソーシングでの入札規律と関係維持の両立 |
| **カーブアウト** | スタンドアロン・イシュー（経理・人事・法務・IT/ERP）の棚卸しとTSAコスト見積り、分離後の管理部門構築、親会社ブランド・取引先依存の解消、配賦費用の実態把握。JIPは「CEOを含む役員を送り込む」ハンズオン |
| **非公開化（TOB/MBO）** | 2指針の理解、特別委員会・MoM・フェアネスオピニオン、TOBプレミアム相場と対抗TOBのゲーム理論（富士ソフト：KKR対ベイン等）、アクティビストの価格介入への備え、スクイーズアウト、大型LBOのシンジケーション |
| **ロールアップ／ボルトオン** | 同業小規模企業の連続買収と統合。業界再編の絵と各オーナーとの個別交渉の並行 |
| **地銀との関係** | レンダー・紹介者・競合・共同投資家の使い分け。利益相反の調整 |
| **LBOファイナンス** | メガ3行アレンジ中心の市場でタームシートを読む力、EBITDA定義・ヘッドルーム・抵触時対応（全銀協報告書が論点整理） |
| **W&I保険** | 数十億円規模から検討、限度額10〜25%、免責0.5〜1%。PE売主のクリーンexit設計 |

### 2-4. 投資後のバリューアップに求められる能力
1. **100日プラン**：クロージングはスタートライン。マネジメントインタビューから始め（ポラリス「すべてはマネジメントインタビューから始まる」）、投資前プロジェクションを現場で修正し中期経営計画に落とし、約100日後の取締役会で決議。カーライルは「WHAT／WHO／by WHEN」と「見える化」。初期会議体はKPI・キャッシュブリッジ・障害除去の3議題固定、60分、アクションとオーナーを24時間内に文書化
2. **経営人材**：最も外部招聘されるのはCFO。ベインBCEP（CxO候補を採用→複数投資先で変革経験→投資先CxOへ転籍）、JIPはCEO含む役員派遣、インテグラルはi-Engine（常駐）、NSSKはNVP®
3. **具体テーマ**：価格改定、粗利率改善、営業改革、管理会計導入、人材・組織強化、追加買収、exit準備、DX、海外展開
4. **入り込み**：投資後半年〜1年は高頻度訪問、業務外のコミュニケーション
5. **組織化**：インハウスのオペレーション部門か、元経営者ネットワークの起用か

### 2-5. 日本語の既存学習手段とその限界
| 象限 | 代表 | 限界 |
|---|---|---|
| 実務書 | 佐山・山本『バイアウト』（2009、唯一級の通貫実務書だが古い）、幸田編『PE投資の実践』（俯瞰的）、日本バイアウト研究所シリーズ（事例集） | 投資判断の訓練（なぜその価格か・何を外したか）にならない。2009年以降の非公開化指針・W&I・地銀ファンドを反映せず |
| 売り手向け | 『PEファンド活用の教科書』、日本M&Aセンター事例集 | 投資家側のDD・ファイナンスを扱わない |
| 選考対策 | エージェント系セミナー（LBOモデル・想定問答） | 「入るため」の訓練。入社後3〜5年の実務を教えない |
| LP・金融機関向け概論 | 日経ビジネススクール、JPEAセミナー（会員限定） | モデリング・交渉・現場を扱わない |
| **空白** | 日本の指針に基づく非公開化の実務演習、LBOローン契約演習、承継オーナーとの関係構築ロールプレイ、カーブアウトTSA設計演習、100日プラン模擬運営、投資先取締役の振る舞い、exit戦略設計 | **→ 道場が埋めるべき領域** |

**総括**：日本語教材は「売り手向け解説」「事例集」「選考対策」「LP向け概論」に偏り、**投資家として一案件を起点から出口まで通貫で模擬する訓練**と、**事業承継・カーブアウト・非公開化の日本固有3類型への判断訓練**がほぼ存在しない。

## 3. 判断力はどう育つか（教育研究と専門職訓練）

### 3-1. ビジネススクールのPE教育
- ケースメソッドが主。**視点で順序づける**（LP→GP→投資先→exit）。Wharton FNCE 751は「バイアウト→M&A」2モジュール、ケース毎に設問、LBOモデリング課題は約10%。FNCE 883はケースライトアップ20%×2、クイズ20%、最終グループ課題30%。HBSは参加が成績の約50%。Stanford FINANCE 587は**模擬投資審査委員会**プレゼンが最終課題。ColumbiaのKKRコンペは学生がLBO対象をKKR幹部（IC役）にピッチ
- 使われるケース：RJR Nabisco、Hertz、Toys R Us、Blackstone/Celanese（交渉シミュレーション）、HCA LBO Exit、Yale Investments Office（LP視点）。**公開された結末があるケースは本当の事後検証ができる**

### 3-2. 実務者トレーナーの順序
Wall Street Prep／BIWS／Peak Frameworks／10X EBITDAは**忠実度の順**に並べる：紙LBO→30分基本テスト→1〜2時間標準テスト→3〜4時間上級テスト（5〜15頁の資料パケット）→持ち帰り3表LBO＋メモ/資料。評価は**モデルの正確性・仮説の質・経営層への伝達力**の3本柱。

### 3-3. 学習科学の知見
| 知見 | 含意 |
|---|---|
| 認知的徒弟制（Collins/Brown/Holum）：モデリング→コーチング→足場→言語化→振り返り→探索。「複雑性を増す」「多様性を増す」「全体→局所」 | 紙LBOを**端から端まで**先に教え、その後デットスケジュールの細部へ |
| ワークド・エグザンプルとフェーディング（Sweller）：初学者には手本が問題解決より効く | 完成したモデル構築を見せてから作らせる |
| 想起練習（Butler 2010；Dunlosky 2013）は応用問題への転移を高める。分散学習と並び最高効用 | ドリルは講義直後と1/3/7/14日後 |
| 混合練習（Rohrer & Taylor）：新規問題で30〜50%向上 | 10問セットは工程混合 |
| 習熟度ベースの学習＋意図的練習（McGaghie）が「見て・やって・教える」に代わる | 進級は時間でなく合格基準で |
| 木こり法（チェス）：固定問題集を1/3/7/14日の周期で反復、毎周速く | パターン認識段階の雛形 |
| FAAシナリオ訓練：判断は「説明→練習→管理・決断」の尺度で、操作技能と**別に**採点 | 技能と判断の2つの尺度 |
| プレモーテム（Klein）：リスク発見約30%増。基準率予測（Kahneman/Flyvbjerg）。校正訓練（Tetlock：Brier 0.166 vs 0.259）。判断ジャーナル（Mauboussin） | 全ケースに組み込む |
| ShadowBox（専門家の順位との比較訓練）：3時間で専門家一致度+28% | 「並べ替え→専門家の順序と理由」を主力型に |
| Script Concordance Test：新情報で仮説をどう更新するかを専門家分布と比較 | 「確信度更新」型を導入 |
| MCQは知識を測るが推論を測らない（医学教育） | 4択は想起専用に |
| ICメモ実務：97%の機関にメモのテンプレがあるが、**事後のメモ検証をする機関はほとんどない**（Addepar/Stanford、54機関） | 道場は判断ジャーナルと事後検証でこの空白を埋める |

## 4. 統合 — 道場v2への要求（結論）

1. **カリキュラムの軸は投資プロセスの工程**（ソーシング→スクリーニング→一次入札→DD→値付け・資金→最終入札・SPA→クロージング→100日→保有→exit）。大手のIC運営・各工程のジュニア成果物（§1-3）がそのまま章立てになる
2. **初級＝アソシエイト1年目の工程遂行**。IM要約・紙LBO・DDトラッカー・ICメモ初稿・Q&A管理。「落とさず・間違えず・速く」
3. **モデルの四段階**（使える→分解できる→疑える→超えられる）。大手の面接が試すのは「モデルの後の30分」（前提の詰め・真のレバー）。日本の選考も「何件か」でなく「どの前提をどう検証し価格に反映したか」
4. **判断の言語化**：ICメモ（反証可能な2〜3の主張・下方・プレモーテム）、「何を信じる必要があるか」、「何があれば降りるか」。Blackstone型のIC規律を模擬ICに
5. **通しケース＋枝ケース**：日本の3類型（事業承継・カーブアウト・非公開化）＋ロールアップ・ターンアラウンド・破談・SBO・危機
6. **人と現場と関係**：日本PEは「人間味」「信頼」「経営者に可愛がられる」を明記する。地銀の4つの顔、仲介との付き合い、オーナーの心情——これらを「ソフトスキル」ではなく**判断の型**として教える
7. **問題の型を判断中心に**（06）、**講義を手本中心に**（05）、**校正と判断ジャーナル**（07）
8. **日本語教材の空白を正面から埋める**：非公開化の指針実務、LBOローン契約、オーナー関係構築、TSA設計、100日プラン運営、投資先取締役、exit設計
