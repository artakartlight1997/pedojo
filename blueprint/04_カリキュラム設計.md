# 04. カリキュラム設計 — 一本道のラーニングジャーニー

> 骨格は**投資プロセスの工程**。背骨は**通しケース「◯◯精機」**。
> 素人は第0章から順に進めば、途中で「何のために」が分からなくなる瞬間がない。

---

## 1. 全体像（3周 × 12章）

```
          第0章 入門 ─┐
  1周目  第1章 ソーシング → 第2章 スクリーニング → 第3章 一次入札 → 第4章 DD →
 「作れる」  第5章 値付け・資金 → 第6章 最終入札・SPA → 第7章 クロージング →
          第8章 100日 → 第9章 保有 → 第10章 exit → 第11章 事後検証
                    ↓ 同じ案件を、VPの視点で
  2周目  第1〜11章（設計し回す）＋ 枝ケースA〜D
 「設計できる」
                    ↓ 同じ案件を、ディレクターの視点で
  3周目  第1〜11章（判断し責任を負う）＋ 枝ケースE〜H
 「判断できる」
```

- **章＝業務工程**。章の中に「工程講義（複数）→演習→ケース章」が入る
- **周＝職位の視点**。1周目で全工程を薄く通し、流れを一本につなぐ。2周目・3周目で同じ工程を厚くする
- v1の「27トピック」は**索引**として残す（用語集・参考資料から辿れる）が、学習ルートの単位にはしない

## 2. 第0章 入門（全周共通・1周目の最初）

| 項目 | 内容 |
|---|---|
| 問い | この仕事は何をする仕事で、プロはどこで差がつくのか |
| 講義 | ①PEの儲け方を一枚で（買う→借入→価値を上げる→売る→LPに返す）②投資プロセスの地図（第1〜11章の予告）③職位と仕事（アソシエイト1年目の一週間）④「落とさない・間違えない・速い」⑤モデルは使える→分解→疑う→超える、の予告 ⑥日本のPE市場（事業承継5割・カーブアウト・非公開化・地銀・仲介） |
| 演習 | 紙LBOの最初の一本（手本を見て、穴埋め、独力） |
| ケース | 「◯◯精機」の会社紹介（まだ案件になっていない状態）。登場人物の顔を覚える |
| 所要 | 3時間 |

## 3. 1周目（作れる）— 章ごとの構成

各章は **[工程講義] → [演習セット] → [ケース章] → [判断ジャーナル]** の順。所要は通しケース07の時間＋講義・演習。

| 章 | 工程講義（05の型で各2,500〜4,000字） | 主な演習型（06） | ケース章の成果物 | 所要 |
|---|---|---|---|---|
| **1 ソーシング** | 1-1 案件はどこから来るか（地銀・仲介・FA・直接）／1-2 投資テーマと「見る／見ない」の初動／1-3 初回面談と24時間以内の動き／1-4 NDAの読み方 | 場面判断、順序 | 地銀面談メモ、投資テーマ適合判定 | 3h |
| **2 スクリーニング** | 2-1 ティーザー・IMの読み方と疑い方／2-2 EV/EBITDA目線の立て方／2-3 紙LBOで入札上限の目安／2-4 2頁スクリーニングメモの型／2-5 業界を1日で調べる当たり順 | 紙計算、最初に確認する数字、メモ赤入れ | スクリーニングメモ、紙LBO | 5h |
| **3 一次入札** | 3-1 簡易LBO（30分版）の組み方／3-2 投資仮説の初稿「何を信じる必要があるか」／3-3 一次入札レターの構造／3-4 プロセスレターと日程逆算／3-5 ICへの最初の報告 | モデル穴埋め、順序、ICの質問を書く | 簡易LBO、一次入札レター、仮説3項目 | 6h |
| **4 DD** | 4-1 DD論点の立て方（仮説から逆算）／4-2 Q&A質問状と依頼リスト／4-3 財務DD：QoE・ネットデット・運転資本の読み方／4-4 ビジネスDD：市場・顧客・競合の検証／4-5 経営者面談の設計と沈黙／4-6 現場視察で見るもの／4-7 専門家との付き合い方／4-8 DD中間報告をモデルに反映する | 並べ替え（DD優先順位）、確信度更新、最初に確認する数字、場面判断 | DD論点リスト、Q&A、面談質問、視察メモ、修正モデル | 8h |
| **5 値付け・資金** | 5-1 フルLBO（3時間版）／5-2 リターン分解と感応度／5-3 バリュエーションの三角測量（コンプス・DCF・LBO逆算）／5-4 タームシートの読み方／5-5 銀行2案の比較／5-6 メザニン・ユニットトランシェの要否／5-7 ストラクチャーの基本（株式譲渡・SPC・ロールオーバー）／5-8 税務がキャッシュを変える場面 | 紙計算、リターン分解、モデル誤り発見、比較表 | フルLBO、分解表、感応度、タームシート比較 | 10h |
| **6 最終入札・SPA** | 6-1 ICメモの型（ルーブリック）／6-2 下方ケースとプレモーテム／6-3 SPAの主要条項をDD発見と対応させる／6-4 価格調整（ロックドボックスvs完成勘定）／6-5 表明保証・補償・W&I／6-6 模擬ICの作法 | ICの質問を書く、プレモーテム、メモ赤入れ、確信度更新 | **ICメモ5頁**、SPA論点表、模擬IC回答 | 8h |
| **7 クロージング** | 7-1 CP管理とサイニング後の規律／7-2 クロージング・チェックリストと資金フロー／7-3 当日の事故の型／7-4 規制届出の日程 | 順序、場面判断 | チェックリスト、資金フロー、事故対応 | 3h |
| **8 100日** | 8-1 クロージングはスタートライン／8-2 マネジメントインタビュー／8-3 100日プラン（WHAT/WHO/by WHEN）／8-4 KPIと会議体の設計／8-5 経営陣・従業員への初動 | 順序、場面判断、生成（施策3つ） | 100日プラン、経営陣面談メモ | 4h |
| **9 保有** | 9-1 月次モニタリングと差異分析／9-2 コベナンツ見込みと銀行への先回り／9-3 ボルトオンの簡易検討／9-4 取締役会の運営 | 計算、場面判断、確信度更新 | 月次差異分析、コベナンツ見込み、ボルトオン簡易検討 | 4h |
| **10 exit** | 10-1 exit経路の比較／10-2 セルサイドの準備（VDD・エクイティストーリー）／10-3 買い手選定（価格×確度）／10-4 売却プロセスの運営／10-5 クリーンexitとW&I | 比較、計算、場面判断 | exit比較、準備リスト、買い手選定 | 5h |

**1周目合計：約62時間（講義20h・演習22h・ケース20h）。**

## 4. 2周目（設計し回せる）— VPの視点

同じ11章を、**「自分が工程を設計し、専門家・相手方・部下を使って回す」**視点で。講義は2周目版（05の第2層）。主な追加：

| 章 | 2周目で加わる講義・成果物 |
|---|---|
| 1 | セクター仮説の立て方。地銀・仲介・FAとの年間関係設計。「紹介者への中間報告」 |
| 2 | スクリーニング会議の仕切り。見送り理由の言語化と「こうなれば検討できる」の残し方 |
| 3 | 簡易LBO→IC初稿を部下に任せてレビューする。レターの交渉余地の設計 |
| 4 | DDスコープと予算の設計。専門家3チームの統括。Q&Aプロセスの運営。経営者面談のリード。発見事項のリスクマップ（価格・契約・保険・PMI） |
| 5 | 銀行との条件交渉。メザニン・コインベストの組成。ストラクチャー比較（税務含む）。ウォークアウェイ価格の決定根拠 |
| 6 | ICメモ主筆。SPA交渉（弁護士との協働）。模擬ICで全質問に防衛 |
| 7 | クロージング事務の統括。サイニング後の対象会社との距離（ガンジャンピング） |
| 8 | 100日プランの主導。CFO招聘の要否。番頭の処遇の実行 |
| 9 | 取締役会の事務局。ウェーバー交渉。ボルトオンの実行 |
| 10 | セルサイドFAの起用。VDDの要否。re-trade対応 |
| 11 | チームのポストモーテム運営。LP報告資料 |

**＋枝ケースA〜D**（カーブアウト・非公開化・ターンアラウンド・ロールアップ）各2〜6時間。
**2周目合計：約70時間。**

## 5. 3周目（判断し責任を負う）— ディレクターの視点

同じ11章を、**「買うか・いくらか・誰とやるか・いつ降りるか」**の視点で。講義は3周目版（05の第3層）。主な追加：

| 章 | 3周目で加わる講義・成果物 |
|---|---|
| 1 | 独自案件を作るソーシング。オーナーとの数年の関係。地銀の4つの顔の使い分け |
| 2 | 「見送り」の決断と、断り方。パイプライン会議でのIC上程判断 |
| 3 | 先制入札の判断。価格レンジの上限を決める論理 |
| 4 | ディールキラーの判定と撤退の進言。経営者の見立てを防衛する |
| 5 | 入札上限（ウォークアウェイ）の最終決定。レバレッジの上限と下方耐性 |
| 6 | ICでの決断。反対意見への対応。「この案件で最も恥ずかしい失敗」の名指し |
| 7 | 破談の瀬戸際の判断（追加投入か撤退か） |
| 8 | 社長交代の判断と伝え方。経営陣インセンティブの設計 |
| 9 | 業績悪化時のエクイティキュア・追加出資・損切りの判断。リキャップの可否 |
| 10 | exitのタイミング。価格×確度の最終選択。継続ファンドや部分売却の是非 |
| 11 | ファンド全体への貢献の総括。次号ファンドへの材料。LPへの悪い数字の報告 |

**＋枝ケースE〜H**（破談・SBO・共同投資・投資先の危機）。
**3周目合計：約60時間。**

**道場完走：約190〜200時間。** 週10時間なら約5か月。これは「一人前（アソシエイト〜シニアアソシエイトとして実務を主担当で回せる）」までの道。

## 6. 用語その場解説（v1②の維持）と用語集の位置

- 講義・問題・ケース本文中の用語は、タップでその場解説（維持）
- 用語集336語は維持・拡充。ただし**用語集を「読む」ことは学習ルートに入れない**。用語は工程の中で出会う
- 各工程講義の§6「その場の用語」が、用語集への入口

## 7. 10問セットと途中再開（v1①の維持）と出題の仕組み

- 10問セット・途中再開は維持
- セットの構成は06-§7の固定比率（用語1・計算2・場面3・並べ替え/確信度2・生成1・復習1）
- **出題範囲＝「今いる章」6割＋既習章の混合4割**。章を進めるほど混合の母集団が増える
- 復習箱：間違えた問題を1/3/7/14日後に再出題

## 8. 進捗の定義（v1⑤「5000問制覇」の再定義）

| v1の進捗 | v2の進捗 |
|---|---|
| 解いた問題数 | **章ごとの成果物の合格バンド**（未着手／手本を見た／独力で作った／合格） |
| 正答率 | **スキルマップ（03）のセル達成状況** |
| 連続日数 | 維持（習慣化の装置として） |
| — | **校正ギャップ**（自己採点と模範の差）の推移 |
| — | **判断ジャーナルの件数と、失敗チェックリストの成長** |
| — | 紙計算の速度（10分紙LBOの達成） |

「5,000問」は**ドリルの母集団の規模**として維持する。制覇の対象は問題数ではなく、**3周×11章の成果物と8本の枝ケース**。

## 9. 章の進級条件（習熟度ベース）

- 章の演習セットで、計算・場面判断の正答率80%以上
- ケース章の成果物を提出し、自己採点を記録（バンドは問わない——1周目は「作った」ことが進級条件）
- 判断ジャーナルを書いた
- 2周目以降：成果物がアソシエイトバンド以上（2周目）、VPバンド以上（3周目）
