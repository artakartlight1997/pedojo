# 06. 問題と演習の設計 — 「正解を選ぶ」から「判断を作る」へ

> 5,000本ノックは維持する。ただし、**何を5,000回反復するか**を変える。
> v1：用語と知識の4択を5,000回。v2：工程ごとの判断・計算・批評・生成を5,000回。

---

## 1. 教育研究が言うこと（設計の根拠）

| 知見 | 出典 | 道場への含意 |
|---|---|---|
| 4択（MCQ）は知識は測るが、推論は測らない。MCQ成績と判断力テストの相関は低い | 医学教育研究（Script Concordance Test文献） | 4択は「用語確認」枠に限定 |
| 想起練習（テスト形式での学習）は応用問題への転移を高める。分散学習と並び最高効用 | Dunlosky 2013、Butler 2010 | ドリルは講義直後と1/3/7/14日後に反復 |
| 混合練習（インターリービング）は新規問題で30〜50%成績向上 | Rohrer & Taylor | 10問セットは複数工程の混合で出す |
| 専門家の優先順位との比較訓練（ShadowBox）は3時間で判断の専門家一致度+28% | ShadowBox研究（DARPA） | 「並べ替え→専門家の順序と理由を見る」型を主力に |
| 新情報で仮説をどう更新するか（Script Concordance）が臨床判断を鍛える | Nouh/Lubarsky | 「新事実で確信度は上がるか下がるか」型を導入 |
| プレモーテムはリスク発見を約30%増やす | Klein（HBR 2007） | 「この案件が失敗した。原因3つを書け」型 |
| 校正訓練（予測→採点）で判断の校正が改善 | Tetlock | 「推薦する確率を書く→結果と比較」を通しケースに |
| 判断ジャーナルはプロセスと結果を分離する | Mauboussin | 全ケースに「判断記録」を必須化 |

**結論：4択を主役にした時点で、判断力は育たない。**

## 3. 5,000問の配分（v1→v2）

| 区分 | v1（4,309問） | v2目標（5,000問） | 比率 |
|---|---|---|---|
| 用語確認4択（型14） | 約210＋多数の知識4択（実質約3,000） | **500** | 10% |
| 紙計算・数値短答・順序（型9,10,11） | 約170 | **1,250** | 25% |
| 場面判断4択（型13）＋最初に確認する数字（型5） | 約580 | **1,250** | 25% |
| 並べ替え・確信度更新・モデル誤り発見（型2,3,4） | 0 | **1,000** | 20% |
| 生成型：ICの質問・プレモーテム・赤入れ・基準率（型6,7,8,12） | 0 | **750** | 15% |
| 通しケース・枝ケースの設問（型1） | 0 | **250** | 5% |

**既存4,309問の扱い**：
- p-laneの場面判断（約580問）→型13としてそのまま再配置（工程タグを付け直す）
- 【計算】約170問→型11へ再配置、検算の形式を統一
- a-lane判断問題→型13へ再配置（3周目の難度）
- 純粋な用語4択→型14枠（500問）に収まる分だけ残し、残りは「用語集の例文」へ格下げ（出題しない）
- 中級の知識4択→可能なものは「場面」を付けて型13へ書き換え、不可能なものは廃棄

**廃棄を恐れない。** 使われない問題は無いのと同じ。

## 4. 全問共通のメタデータ（タグ）

```
{
  id, type(1-14),
  stage(工程ID: 例 "S2-screening"),      // どの業務工程の反復か
  lap(1|2|3),                             // 作れる／設計できる／判断できる
  archetype(["succession","carveout","p2p","turnaround","rollup","generic"]),
  risk(["revenue-quality","customer-conc","mgmt","leverage","legal","tax",...]),
  skill(["model","fa","negotiation","people","process",...]),
  case(通しケース/枝ケースのID or null),  // ケースに紐づく問題か
  calc(true/false), rubric(ルーブリックID or null),
  source("v1:lbo-a#17" 等)                // 再編元
}
```
タグがあることで、**インターリービング（混合出題）と間隔反復（1/3/7/14日）を自動化**できる。

## 5. 4択を書くときの規律（型13・14）

- **全選択肢が「一理ある」こと**。明白な誤りで埋めない
- **正解が最長にならない**（SOLV=0ゲートは維持）
- **根拠を選ばせる**：選択肢は「判断＋理由」の形。「Aをする——なぜなら…」
- **解説は「なぜ他がダメか」も書く**（最低2つの不正解について）
- 場面には**職位・時点・相手**を書く（「DD3週目、VPのあなたに売主FAから電話」）

## 6. 生成型問題の採点（ルーブリック）

自動採点できない型（6,7,12、ケース設問）は、**3段階バンド付きルーブリック**で自己採点する。

```
バンド：アナリスト（型どおり）／アソシエイト（論点が立つ）／VP（判断を防衛できる）
各観点に「VPバンドの例」を1つ付ける（模範解答ではなく、水準の見本）
学習者は自己採点→模範のバンド判定を見る→ギャップを記録（校正指標）
```

例：「ICの質問を書く」のルーブリック
| 観点 | アナリスト | アソシエイト | VP |
|---|---|---|---|
| 的 | 一般的な質問（「リスクは？」） | メモの特定の数字・主張を指す | **結論を動かす前提**（荷重のかかる主張）を正確に指す |
| 検証可能性 | 答えようがない | 答えられる | 答えに必要な資料・手続きまで想定している |
| 言葉 | 長い・曖昧 | 簡潔 | 一文。委員会でそのまま使える |

## 7. 10問セットの組み方（v1①の維持と改良）

- 1セット＝10問、途中再開可（維持）
- **構成を固定**：用語確認1／紙計算2／場面判断3／並べ替えor確信度更新2／生成型1／前セットの復習1
- **「今やっている工程」の問題が6割、過去工程の混合が4割**（インターリービング）
- 間違えた問題は復習箱へ（維持）。1/3/7/14日後に再出題

## 9. 書き手への指示（問題作成の手順）

1. 対象工程の講義（§3手本・§4型・§5落とし穴）を読む
2. その工程で**プロが実際に迷う判断**を3つ書き出す
3. 迷いごとに、型2〜13から最も合う型を選ぶ（4択は最後の選択）
4. 場面を書く（職位・時点・相手・手元の情報）
5. 判断と理由を書く。不正解には「なぜそう考えたくなるか」を書く
6. 解説に「→第◯章」で講義とケースへの参照を付ける
7. タグを付ける。lintを通す
