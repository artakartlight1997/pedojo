# 09. ロードマップ — 何から、どの順で作るか

> 原則：**最初から全部を作らない。1周目を端から端まで通せる状態を最速で作り、使ってもらい、直す。**
> 「学習者が第0章から第11章まで一本で歩ける」ことが最初のマイルストーン。深さは後から足す。

---

## フェーズ0：設計の確定（本フェーズ・完了）
- `blueprint/00〜09` を書き起こし、思想・診断・リサーチ・スキルマップ・カリキュラム・講義/問題/ケースの設計・実装方針を確定
- **ユーザー確認事項**（10章で後述）への回答を受けて微修正

## フェーズ1：背骨を立てる（1周目を一本で通す）
目標：**第0〜11章を、アソシエイト視点で一周できる**。各章は「工程講義（最小構成）→演習セット→ケース章→ジャーナル」が揃っている。

| 順 | 作業 | 完成の定義 |
|---|---|---|
| 1-1 | 通しケース「◯◯精機」の**会社設定・登場人物・年表・全章の資料一式**（company.js＋ch02〜ch11の資料）を先に書き切る | 11章分の「状況の提示」資料が実物として揃う。罠4つ・答えのない論点2つが埋め込まれている |
| 1-2 | アプリ機構の最小実装：章ビュー／成果物エディタ／ルーブリック自己採点／プロの成果物の開示順序／判断ジャーナル／確信度記録／エクスポート | e2eスイート追加・通過 |
| 1-3 | 第0章（入門）＋第2章（スクリーニング）を**完全版**で作る（講義・演習・ケース・ルーブリック） | 著者自身が第2章の成果物を作り、ルーブリックで採点できる |
| 1-4 | 第3・5章（モデル四段階の「使える」「分解できる」） | 紙LBO・簡易LBO・フルLBOの手本と穴埋め演習。自動検算 |
| 1-5 | 第4章（DD）・第6章（ICメモ・模擬IC） | ICメモルーブリック、模擬IC8問が動く |
| 1-6 | 第1・7・8・9・10・11章 | 各章の最小構成 |
| 1-7 | v1問題の機械移行（migrate-v1.js）＋配分レポート | 既存問題が章・周・型でタグ付けされ、出題に乗る |
| 1-8 | 通し検証：著者が第0→11章を**実際に一周**し、途切れ・分からなくなる箇所を全部直す | 「何のために」が切れる箇所ゼロ |

**フェーズ1の成果**：1周目完走可能。講義約45本、ケース章11、ルーブリック約15、演習セット約60。

## フェーズ2：厚みを足す（2周目＋枝A〜D）
- 11章の2周目講義（VP視点）と2周目のケース任務
- 枝ケースA（カーブアウト）・B（非公開化）・C（ターンアラウンド）・D（ロールアップ）
- 問題の新型（並べ替え・確信度更新・モデル誤り発見・生成型）を各章に配備し、配分（06-§3）を目標の±20%内に
- スキルマップ画面を進捗の主役に

## フェーズ3：判断を鍛える（3周目＋枝E〜H）
- 11章の3周目講義（ディレクター視点）と3周目のケース任務
- 枝E（破談）・F（SBO）・G（共同投資）・H（投資先の危機）
- 基準率・プレモーテム・校正の仕組みをフル稼働
- 公開事例（海外：RJR Nabisco／Toys R Us／Hertz／HCA、日本：公開情報で語れる事例）の教訓を枝ケースの参照に

## フェーズ4：5,000本と磨き込み
- 問題バンクを5,000問・目標配分に到達させる（**新規は06-§9の手順で、講義・ケースから生む**）
- 学習効果の指標（08-§7）で弱い章・型を特定して補強
- 用語集の拡充（工程講義§6から逆引き）

## マイルストーンと測定

| MS | 条件 | 測定値（コミットに書くもの） |
|---|---|---|
| MS1 | ケース資料一式＋アプリ機構 | ケース章数11（資料のみ）、e2e通過 |
| MS2 | 第0・2章完全版 | 講義N本・演習セット・ルーブリック・著者の成果物採点記録 |
| MS3 | 1周目完走可能 | 全11章の最小構成、著者の一周ログ、途切れ箇所0 |
| MS4 | 2周目＋枝A〜D | 2周目講義・任務、枝4本、配分達成度 |
| MS5 | 3周目＋枝E〜H | 3周目講義・任務、枝8本 |
| MS6 | 5,000問・配分達成 | 配分表、SOLV=0、lint、e2e |

---

## 作業の規律（NOTES.mdに引き継ぐ）
1. 章単位で完成させる。講義だけ・問題だけの先行量産をしない
2. 各章で著者が成果物を自分で作る
3. 毎コミットに測定値（章・講義・ケース・ルーブリック・配分・SOLV・lint・e2e）
4. 言語混入・SOLV・タグ・7節・ルーブリック・検算のゲートを通す
5. 用語4択は全体の10%以下を守る
6. 日本の現場を主軸に、海外の型は参照として明示

## 10. ユーザーに確認したいこと（回答があれば反映。なければ下の既定で進める）

| # | 論点 | 既定 |
|---|---|---|
| 1 | 通しケースの業種：製造業（精密部品・事業承継）で良いか。別業種（サービス・小売・ソフトウェア）を希望するか | 製造業・事業承継（日本で最多の型） |
| 2 | 1周目の到達目標：「アソシエイト1年目の仕事を意味を理解して遂行できる」で良いか | 良い |
| 3 | 完走想定時間：約190〜200時間（週10時間で約5か月）で良いか。もっと短く／長く | 良い |
| 4 | 旧コンテンツ：出題対象外にする用語4択を**残す**（用語集の例文）か、削除するか | 残す（出題しない） |
| 5 | モデル演習：ブラウザ内の簡易表入力で良いか、Excelファイル（ダウンロード→手で組む→答え合わせ）も併用するか | 簡易表入力＋Excelテンプレ配布の併用 |
| 6 | 英語：海外大手の原語（IC memo, what we need to believe 等）を併記するか | 初出のみ併記 |
