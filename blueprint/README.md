## 一枚要約

- **到達点**：一つの案件をソーシングからexitまで自分の手で運べる。アソシエイト〜シニアアソシエイトとして実務を主担当で回せる水準（1周目＝作れる／2周目＝設計し回せる／3周目＝判断し責任を負う）
- **骨格**：知識領域ではなく**投資プロセスの工程**（12章）。**通しケース「◯◯精機」**（事業承継×製造業）が背骨、**枝ケース8本**（カーブアウト・非公開化・ターンアラウンド・ロールアップ・破談・SBO・共同投資・危機）で型を転用
- **講義**：プロの手本（思考過程つき）が本体。用語は末尾に最小限。モデルは「使える→分解できる→疑える→超えられる」の四段階で、**モデルだけではだめ**を構造で教える
- **問題**：4択は用語確認の10%以下。主力は紙計算・場面判断・並べ替え（専門家比較）・確信度更新・モデル誤り発見・ICの質問を書く・プレモーテム・メモ赤入れ。5,000問は維持し配分を変える
- **ケース**：各章で成果物を作り、プロの成果物と比べ、ルーブリックで自己採点し、判断ジャーナルを書き、確信度を記録して最終章で結果と比較する
- **日本**：事業承継5割・カーブアウト・非公開化・地銀の4つの顔・仲介・経営者との信頼を主軸に。海外大手の型は参照
- **測定**：問題数ではなく、章の成果物の合格バンド・スキルマップのセル・校正ギャップ・紙計算の速度で進捗を測る
